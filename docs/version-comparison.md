说明：

- 2.99.0.0 与 2.99.0.1 的拦截点数量、位置、形态完全一致；只有下架文案从“PCL 暂时不再提供…”变成“PCL 不再提供…”，因此规则按前缀匹配。
- 2.13.1.1 是限制上线前的版本，0 个拦截点，可作为“功能正常时应有的行为”的对照基线。
- 陷阱点 `runtime-compare(trap)`（FormMain 的拖拽异常处理）是真实运行时字符串比较，两个受限版本都存在，工具只报告、不修改。
